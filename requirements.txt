# One Cedric — runtime dependencies
#
# Install with:      pip install -r requirements.txt
# Everything else:   pip install -r requirements-optional.txt
# Development tools: pip install -r requirements-dev.txt
# Or install every extra at once:  pip install -e ".[all]"
#
# Versions below are the ones the project is developed and tested against.
# Missing optional packages are not fatal: the in-app Diagnose panel lists
# exactly what is missing and the pip command that fixes it.
